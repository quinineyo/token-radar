Token launch radar for make.fun's token-radar-01 bounty: it reads a sealed DefiLlama snapshot, ranks every pre-token protocol by an implied value priced from live-market multiples, and serves a static dashboard with a farm plan for each protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
